# GLibs

**Global Code Libraries** — набор библиотек для проектов команды Global Code.

> ⚠️ **Note on naming:** The name "GLibs" is an abbreviation of **Global Libraries** and is not affiliated with, endorsed by, or related to Google or any of its products (e.g., Google Libraries, Google Libs).

## About

Модули и библиотеки для запуска программ команды Global Code.
